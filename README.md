# Cronograma de Mariana Meza en Argentina (9 oct – 13 dic 2026)

Dashboard interactivo para GitHub Pages.

## Editar
Todo se configura al inicio del <script> en index.html:
- CONFIG.conductas y CONFIG.pilares: nombres de las 5 conductas y los 5 pilares.
- CONFIG.capacidad: farmacias por medio turno en cada área.
- AREAS: farmacias, Gerentes de Área y Coordinadores de RRHH.
- GRUPOS_KICKOFF: tamaño de los grupos de kickoff por área.
- FERIADOS, NO_LABORABLES y CONFIG.pausa.
